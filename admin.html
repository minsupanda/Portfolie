관리자 인증 후 콘텐츠를 수정·저장하고 방문 통계를 확인합니다. 공개 사이트는 로그인 없이 열람할 수 있습니다.

배포 연결이 필요합니다

현재 공개 포트폴리오는 파일만으로 열람할 수 있지만, 관리자 수정·분석 기능은 Supabase 연결 후 사용할 수 있습니다.

  1. Supabase 프로젝트를 만듭니다.
  2. schema.sql의 소유자 UUID를 변경하고 SQL Editor에서 실행합니다.
  3. Supabase Auth에서 소유자 계정 1개를 생성합니다.
  4. admin.html 및 index.html 내 PORTFOLIO_CONFIG에 Project URL과 anon key를 입력합니다.
  5. 정적 사이트로 배포하면 공개 열람과 관리자 전용 편집이 분리됩니다.

안전상의 이유로 구성 전에는 가짜 비밀번호 로그인이나 브라우저 로컬 저장 편집을 제공하지 않습니다.
